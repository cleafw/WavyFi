WavyFi v1.1.0 是 [cleafw/WavyFi](https://github.com/cleafw/WavyFi) 的首个正式发行版，基于 [zhgzhg/WavyFi](https://github.com/zhgzhg/WavyFi)，沿用 MIT 许可证。

## 更新内容

- 图形界面和命令行支持简体中文和英文。界面会记住语言选择，切换时保留已有扫描记录。
- 命令行可用 `--lang zh-CN` 或 `--lang en` 指定输出语言。
- 演示模式 `--demo` 使用模拟网络与设备，便于录屏和截图。双击程序会进入真实扫描模式。

## 下载与使用

支持 Windows 10 版本 2004（内部版本 19041）及以上，包括 Windows 11。图形界面和无线扫描依赖 Windows 接口。

| 架构 | 免安装包（推荐） | 精简包 |
| --- | --- | --- |
| Windows x64（Intel / AMD） | `WavyFi-1.1.0-win-x64.zip` | `WavyFi-1.1.0-win-x64-framework-dependent.zip` |
| Windows ARM64 | `WavyFi-1.1.0-win-arm64.zip` | `WavyFi-1.1.0-win-arm64-framework-dependent.zip` |

解压 ZIP 后双击 `WavyFi.exe`。推荐包已包含运行时。精简包需要同架构的 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)。若真实扫描显示位置访问错误，在 Windows 隐私设置中检查位置访问权限。下载后可用 `SHA256SUMS.txt` 核对 ZIP 的 SHA-256。

## English

This is the first stable release of the `cleafw/WavyFi` fork. It adds Simplified Chinese and English support across the GUI and CLI, preserves scan history when switching the GUI language, and includes a `--demo` mode for screenshots with sample data. Use `--lang zh-CN` or `--lang en` to set the CLI language.

Choose the x64 or ARM64 ZIP for your Windows device, extract it, and double-click `WavyFi.exe` for real scans. The regular ZIP includes the runtime. Packages marked `framework-dependent` require the matching .NET 10 Desktop Runtime. WavyFi requires Windows 10 build 19041 or later. Check package integrity against `SHA256SUMS.txt`.
