# 简体中文本地化说明

本分支提供简体中文和英文两种显示语言。主文档为 [README.md](../README.md)，上游英文说明保留为 [README.en.md](../README.en.md)。原作者、MIT 许可证和数据来源署名保持不变。

## 翻译范围

- 图形界面：工具栏、筛选器、列表表头及说明、右键菜单、复制与导出提示、扫描状态、错误提示、语言选择器。
- 图表：空数据提示、信号历史说明和时间轴提示。
- 核心显示文本：隐藏网络、未命名设备、未知厂商、WiFi Direct 设备类型与配对状态、安全方式的可读说明。
- 建议引擎：周围网络概况、推荐信道、干扰分析、安全升级及 WPS 提示。
- 命令行：帮助、参数错误、扫描状态、结果表格、设备信息及建议。使用 `--lang zh-CN` 或 `--lang en` 选择语言。
- 用户文档：中文主 README 与本说明。`docs/WavyFiScreenshot.png` 保留上游英文界面截图，README 已明确标注。

源代码注释和开发标识不要求全部翻译。

## 有意保留的原始内容

- 网络名称（SSID）、设备名称、MAC/BSSID、网卡名称和真实厂商名称属于扫描数据，保持原样。
- WiFi、WiFi Direct、Miracast、IEEE、802.11、HT/VHT/HE/EHT、MCS、WPA/WPA2/WPA3、WEP、TKIP、AES-CCMP、WPS、DFS 等产品或协议标识保持可识别。
- dBm、GHz、MHz、Mbps、CSV 等单位和格式名保持标准写法。
- `scan`、`p2p`、`--lang` 等命令与选项，以及排序键、路径、注册表键、资源键和 API 名称保持稳定。
- 内部用于筛选和判断的频段、安全类型及设备类型原始值不应因界面语言改变；显示层负责转换为可读文本。
- 面向脚本的 CSV 列名和布尔值保持稳定，具体以命令行输出契约为准。

## 可重复检查

从项目目录运行（Python 3，仅使用标准库，无需安装依赖）：

```powershell
python tools/check_localization.py
```

检查器扫描 `src/`，跳过构建生成的 `bin/`、`obj/`：

1. 校验 XAML XML 格式，并核对 `{loc:Text KEY}` 引用是否存在于 `UiText.cs`。
2. 检查目录键是否重复，报告未被 XAML 引用的目录键供人工复核。
3. 检查 `Locale.T` / `Locale.F` 及静态导入的 `T` / `F` 的双文字面量参数，拒绝空译文。
4. 比较普通格式字符串的占位符编号及次数，也比较内插字符串的表达式及次数；允许译文调整表达式顺序。
5. 报告 XAML 可见属性中的疑似未翻译英文；已知协议、单位、产品名、字体按钮与语言名称不作为遗漏。

缺键、空译文、占位符不一致或无效 XML 会导致非零退出码。`REVIEW` 是需人工判断的提示，不会导致失败；未引用键可能已不再需要，也可能用于其他入口。

这是范围明确的静态检查，并非完整 C# 编译器或翻译质量评分。动态参数、拼接表达式、原始字符串等不在双文字面量校验范围内；输出会统计跳过的调用。检查器不能代替构建、测试及中英文界面的实际检查。

## 人工检查清单

- 分别查看中英文界面，确认较长译文没有遮挡或截断主要操作。
- 检查扫描开启与暂停状态下的语言切换、数据和筛选条件保留。
- 检查无网卡、无线开关关闭、位置权限关闭、暂无结果等提示。
- 检查两个列表、列选择菜单、复制/导出和两个图表。
- 检查中文与英文的 `--help`、无效参数、`scan --advise` 和 `p2p` 输出。
- 确认 CSV 结构、命令参数及真实网络数据不随显示语言改变。
- 中文终端表格还需观察汉字的显示宽度；普通字符填充不一定能在所有终端中对齐。
